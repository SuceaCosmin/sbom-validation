SBOM Validation
===============

This project will validate Software Bill of Materials (SBOM) documents against
industry specifications. The initial format scope is CycloneDX and SPDX, with
BSI TR-03183-2 as the first domain-specific reference.

Requirements are maintained as Sphinx-Needs artifacts. Each normative
requirement should cite its source and version; implementation and test needs
should link back to the requirements they implement or verify.
