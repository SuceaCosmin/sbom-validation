.. admonition:: Key to the fields
   :class: needs-key

   **Status** — ``draft`` wording not agreed · ``approved`` agreed, no code
   marker yet · ``implemented`` code marker, no test marker yet ·
   ``verified`` code and test marker · ``deprecated`` retired.
   **Level** — ``MUST`` mandatory in the standard · ``Conditional`` form is
   checked only if the element is present · ``n/a`` product requirement.
   **Result kind** — ``pass-fail`` · ``form-only`` · ``not-verifiable`` ·
   ``pass-fail-partly-not-verifiable``. Full definitions:
   :doc:`/reading-guide`.
